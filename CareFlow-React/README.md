# CareFlow – Healthcare Appointment System (React + Vite)

A React + Vite conversion of the supplied Health-Care-Appointment-System project. The original blue healthcare visual theme and background image are retained.

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. Open Terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Features

- React single-page application powered by Vite
- Home, Login and Signup pages
- Local Storage registration and login
- Admin dashboard, doctor management (add/edit/delete), appointment approval/rejection/deletion, feedback viewing
- User dashboard, doctor search, appointment booking, appointment status tracking and feedback submission
- Responsive layout

## Important note

This is a frontend academic demonstration. Local Storage is browser-specific and is not secure authentication or a production database. Do not use real patient information or real passwords.
